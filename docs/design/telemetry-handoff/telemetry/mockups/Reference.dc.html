What a MeshCore node can put in a telemetry reply

From SensorManager.h and EnvironmentSensorManager.cpp. Ch 1 is the node itself (battery, then GPS). Environment sensors take ch 2 onward in the order they are detected at boot, so the same sensor can land on a different channel on another board.

0x01Base
Battery voltage on ch 1. Guests on a repeater get this and nothing else.
0x02Location
GPS on ch 1, only when a GPS is detected and switched on (setting gps = 1).
0x04Environment
Every detected I²C sensor, ch 2 onward. Without it the reply stops after ch 1.
